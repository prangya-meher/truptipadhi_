DATA ANALYSIS • MACHINE LEARNING • PYTHON

Netflix Movie Recommendation System

Developed a movie recommendation system for Netflix using collaborative filtering and content-based techniques. Used Python, Pandas, NumPy, and Scikit-learn to analyze user preferences and generate personalized content recommendations.

View Source Code
PROJECT OVERVIEW

Analyzed 7,700+ Netflix titles to address cold-start and catalog discoverability challenges. Preprocessed unstructured metadata across cast, directors, ratings, and plot synopses, and implemented TF-IDF vectorization paired with K-Means and Hierarchical clustering algorithms. Built cosine similarity recommendation matrices to accurately deliver personalized, genre-aligned content matches.

CORE METHODOLOGY

Missing Value Imputation → Text Cleaning & Tokenization → TF-IDF Vectorization → K-Means & Agglomerative Clustering → Cosine Similarity Engine.

DATA ANALYSIS • PYTHON • STATISTICS

Customer Purchase Behaviour Analysis

Analyzed customer demographics and purchasing behavior to identify spending patterns, purchase channels, customer segments, and factors influencing campaign offer acceptance. Used Python, Pandas, and data visualization to uncover relationships and trends that can support more informed marketing decisions.

View Source Code
PROJECT OVERVIEW

Evaluated a detailed consumer dataset examining customer demographic variables (household income, education level, marital status, children/teens) against spending across 6 core product categories and multichannel purchasing frequencies (web, store, catalog). Conducted probability distribution analysis, cross-tabulation, and correlation modeling to identify customer lifetime value segments and determine the key behavioral triggers driving marketing campaign acceptance.

CORE METHODOLOGY

Data Cleaning & Feature Engineering → Spending & Channel Distribution Analysis → Demographic Segmentation → Correlation Heatmaps & Probability Hypothesis Testing.

Social Media Optimization
